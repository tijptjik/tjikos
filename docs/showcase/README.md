# README showcase artwork

Prepared on 2026-10-29.

- `bartjik.png` arranges actual panel captures from the running desktop: music,
  market history, VPN/tailnet, audio, usage, credits, networking, world clocks,
  input methods and both bars. Secondary panels extend beyond the composition. Values are a point-in-time
  view. Panels were opened with native pointer hover; no controls were activated.
- `greetjik.png` combines fresh native terminal renders of `twilight`, `rainbow`
  and `pinkie` with the displayed piped messages. Artwork retains the provenance
  and terms documented in `apps/greetjik/assets/UPSTREAM.md`.
- `tjikup.png` shows the installed native runner's `--demo changed` fixture in an
  isolated Kitty session. The displayed changes are synthetic.

Raw captures and private runtime files are kept outside Git. These PNGs are the
composed README exports. The VPN/tailnet panel includes its live device names
and tailnet addresses; no credentials or account configuration files are included. Synctjik's command map source is `synctjik-tree.mmd`.

- `synctjik.png` lays out the documented command families; it is a diagram, not a
  capture of an archive run. `synctjik-tree.mmd` retains the command-tree source.
- `runtjik.png` combines the installed launcher's real application grid with
  screenshot and recording target menus rendered from the current source in an
  isolated desktop. The source session discovers installed applications, uses
  temporary state, and does not use demo fixtures. No clipboard contents, Fish
  history, window contents or previous capture filenames are shown.
