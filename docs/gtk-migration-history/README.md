# Historical desktop migration records

These reports preserve the implementation chronology and measurements for Bartjik and
Runtjik. They describe earlier source revisions and retired frontend commands. Paths,
links and temporary artifacts are historical and may no longer exist in the current
checkout. Do not use these files as installation or test instructions.

Current operational guidance is in each app README and
[desktop native acceptance](../desktop-native-acceptance.md). Renderer-only test runners
remain available in Git history rather than shipped beside the native application.
