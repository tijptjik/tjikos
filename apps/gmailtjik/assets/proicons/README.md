# Proicons

MIT-licensed SVGs from
[ProCode Software Proicons](https://github.com/ProCode-Software/proicons/tree/b8718fbc0a8654f6065cff8b3166ee3b99cd89ca/icons/svg),
pinned to commit `b8718fbc0a8654f6065cff8b3166ee3b99cd89ca`. See LICENSE. Embedded in
the binary for offline UI rendering.

`label.svg` is a local tag-outline icon using the same 24px grid and stroke weight.

`signature.svg` and `quote.svg` are local outline icons on the same 24px grid with 1.5px
strokes.

`colour-wheel.svg` is a local segmented wheel on the same 24px grid with 1.5px strokes.
