# Material Symbols Rounded

The unmodified official TTF is retained as a licensed design asset. Native icon
rendering uses the bundled vector artwork and morph data. The build verifies the font
size and SHA-256 in `provenance.json`; the upstream Git blob hash supports independent
verification.

Source: <https://github.com/google/material-design-icons>

License: Apache-2.0; see `LICENSE.txt`. The upstream revision and source path are pinned
in `provenance.json`. To update, choose a new explicit upstream commit, download that
exact TTF, verify its Git blob hash, update the size and SHA-256, and run the asset
provenance check before committing all changes together. Do not replace the font from a
floating branch or distro package.
