# Slash-command artwork

Unbranded 64 × 64 SVG object icons for Runtjik. No shared app-identity badge, outer
frame, or Command logo. Each silhouette describes its action. The slash menu and general
search use these bundled assets consistently across machines; third-party commands
retain their provider icon when no companion exists.

Style follows Dotjik's primary frameless Rose Punk guidelines: optical sizing, rounded
object contours, material-specific highlights, folded paper, enamel, steel and glass.
The illustrated palette includes jade, copper, rose, violet, ivory paper and cool steel.
Dark surfaces are used only where the object needs them, such as a terminal screen or
camera viewfinder.

Sources (all original Rose Punk artwork):

- Refresh, pin, grid, list, stats, config and shortcuts are copied from Dotjik's primary
  `rose-punk/scalable/apps/runtjik-*.svg` exports. Their authoritative designs are
  `scripts/icons/material_art.py:COMMAND_ART` in Dotjik.
- Run, GUI and monitor use command-specific Rose Punk icons; grab reuses Dotjik's
  unbranded `system-monitor.svg` and `camera.svg` exports respectively.
- File search, directory jump, emoji search, scratch notes, timers and Bitwarden use
  command-specific Rose Punk object icons drawn in the same palette and frameless style.
- Browser, tabs, clipboard, dictionary, reading, synonym, Todo and recording are
  companion object illustrations authored here, using the material palette from Dotjik's
  `scripts/icons/material_art.py`.

These are self-contained editable SVGs with no fonts or external resources.
