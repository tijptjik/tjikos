# Browser favicon overrides

Simplified publisher artwork copied from
`saanseoi/apps/atlas-app/src/lib/assets/logos/publisher-studies/`:

- `overture.svg`: `overture-fluid-atlas.svg`, for overturemaps.org and subdomains.
- `hkgov.svg`: `hong-kong-fluid-bauhinia.svg`, for csdi.gov.hk and subdomains.

The PNGs are transparent 256px renders of these SVGs for consistent Qt support. These
are SaanSeoi's concept treatments, not official publisher brand assets. Bundled with
Runtjik so overrides work without the SaanSeoi checkout or a network request.
