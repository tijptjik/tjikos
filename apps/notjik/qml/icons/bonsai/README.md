# Cybernetic bonsai collection

24 individually generated illustrations in the approved dark rose-punk ink style. This collection is reserved for future use and is not wired into notifications.

`manifest.json` records every exact prompt, filename, and image dimension. Generated with the built-in image tool.

`contact-sheet.jpg` previews all 24 images in manifest order, using the same four-column layout as the fish collection. The collection lives alongside `fish/` and `robots/` in Notjik's `qml/icons/`.
