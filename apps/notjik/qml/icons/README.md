# Notification fallback artwork

`vintage-robot.png` is the existing Tijpfiles default notification icon, migrated
here so notjik does not depend on retired desktop configuration paths.

Vintage Robot by Lorc, from [Game-icons.net](https://game-icons.net/1x1/lorc/vintage-robot.html),
licensed under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).

`radar-dish.png` restores the earlier Tijpfiles network artwork for wireless
notifications (sender-supplied images still win). Radar Dish by Lorc,
https://game-icons.net/1x1/lorc/radar-dish.html , CC BY 3.0.
