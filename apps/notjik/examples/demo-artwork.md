# Demo artwork

`demo-artwork.png` is an original generated album-cover fixture, created with the
built-in image generation tool on 2026-10-25. It contains no private media or
external runtime dependency. The image demo supplies this PNG alongside a Wi-Fi
icon so both notjik and Dunst can demonstrate sender-image precedence.

Prompt:

> Use case: stylized-concept. Asset type: square album-cover artwork used as a small sender-provided thumbnail in a desktop notification demo. Create a richly textured, full-colour illustration of a moonlit sea with luminous rose-pink reflections and layered dark indigo mountains, striking simple composition legible at 48 pixels, painterly atmosphere. Edge-to-edge square artwork, opaque background. No typography, no logos, no UI, no frame, no checkmarks or icon-like symbols.
